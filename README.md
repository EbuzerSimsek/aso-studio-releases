# ASO Studio — Sürümler

macOS için App Store Optimization aracı. Bu repo yalnızca indirilebilir sürümleri ve
uygulamanın otomatik güncelleme akışını (`appcast.xml`) barındırır.

**İndir:** [En son sürüm](https://github.com/EbuzerSimsek/aso-studio-releases/releases/latest) → `ASOStudio-x.y.z.dmg`

Kurulum: DMG'yi açın, **ASO Studio**'yu **Applications** klasörüne sürükleyin.
İlk açılışta macOS uyarı verirse uygulamaya sağ tıklayıp **Aç**'ı seçin.

Gereksinim: macOS 14 Sonoma veya üzeri (Apple Silicon ve Intel).
